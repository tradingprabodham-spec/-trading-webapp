Quick daily login (2 steps, ~20s):
1) Fill your Upstox API Key and Redirect URI (from your Upstox Developer app) once — click Open Upstox Login, log in, and after redirect grab the code param from the URL bar.
2) Exchange it for a token — run this once (needs your API Secret, never paste that here):
curl -X POST https://api.upstox.com/v2/login/authorization/token -H "accept: application/json" -H "Content-Type: application/x-www-form-urlencoded" -d "code=PASTE_CODE&client_id=YOUR_API_KEY&client_secret=YOUR_API_SECRET&redirect_uri=YOUR_REDIRECT_URI&grant_type=authorization_code" Copy the access_token from the response into the field below. This can't be fully automated in-browser since the token exchange needs your API Secret, which should never sit in client-side JavaScript.
How instrument keys work now: every symbol's instrument key and lot size is resolved live from Upstox's own Instrument Search API when you connect — no hardcoded ISINs, so stock splits/bonus corporate actions can't break it. Token is used only for direct calls from your browser to api.upstox.com. If requests fail with a network/CORS error, that's Upstox blocking cross-origin calls from this page, not something this dashboard controls.
